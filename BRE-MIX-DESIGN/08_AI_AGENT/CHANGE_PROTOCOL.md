# Change Protocol

## Before Any Engineering Change

1. Document the reason for the change
2. Identify the source authority
3. Get approval (if significant)

## During the Change

4. Make the change in the appropriate file
5. Update source register if new source
6. Update traceability matrix
7. Update validation tests if affected
8. Run all existing tests

## After the Change

9. Update changelog
10. Mark verification status
11. Review for unintended side effects

## Forbidden Without Explicit Approval

- Removing functionality
- Modifying engineering data
- Changing validation expected values
- Changing source editions
- Removing tests
