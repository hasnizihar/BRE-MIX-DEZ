# Agent Workflow

## Standard Task Cycle

```
READ AGENTS.md and relevant engineering docs
  ↓
UNDERSTAND the engineering requirement
  ↓
PLAN the implementation
  ↓
IMPLEMENT (code/documentation)
  ↓
TEST (all tests must pass)
  ↓
COMPARE against engineering specification
  ↓
REVIEW for engineering correctness
  ↓
DOCUMENT changes
  ↓
UPDATE traceability and changelog
```
