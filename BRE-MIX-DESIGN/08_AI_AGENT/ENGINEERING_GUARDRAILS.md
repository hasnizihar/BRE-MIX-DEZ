# Engineering Guardrails

## Hard Limits

1. Every engineering value must have a source reference
2. No calculation without unit documentation
3. No table modification without re-verification
4. No graph data modification without re-digitization documentation
5. No test removal or expected value modification
6. No engineering logic in UI layer
7. No silent value selection

## Soft Limits (require justification)

1. Adding engineering assumptions not in primary source
2. Using approximation formulas instead of tabular data
3. Extending valid ranges beyond documented limits
4. Using secondary source values when primary is unavailable
