# DATA-002: Figure 5 Metadata

| Attribute | Value |
| :--- | :--- |
| **Parameter** | Estimated wet density of fully compacted concrete |
| **Source** | BRE BR 331 (Second Edition, 1997) |
| **Section** | 5.4 Determination of total aggregate content (Stage 4) |
| **Page** | 13 |
| **Status** | `SYNTHETIC_PLACEHOLDER` |
| **Type** | Graph (Curve interpolation) |

## Context
This data represents Figure 5 from the standard. It estimates the wet density of fully compacted concrete given the free-water content and the relative density of the combined aggregate (in SSD condition).

## Usage
The result is used in Stage 4 calculation (C4) to determine the total aggregate content by subtracting the water and cement contents from this estimated density.
