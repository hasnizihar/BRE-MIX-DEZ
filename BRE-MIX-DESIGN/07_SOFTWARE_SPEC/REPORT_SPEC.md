# Report Specification

## Report Content

The PDF report should contain:

1. **Header:** Project name, mix reference, date, engineer
2. **Method:** BRE BR 331, Second Edition, 1997
3. **Design Requirements:** f_ck, workability, aggregate details
4. **Calculation Summary:** All intermediate values with equations
5. **Mix Proportions:** Final mix per m³ (SSD basis)
6. **Batch Quantities:** Moisture-corrected quantities
7. **Engineering Checks:** Pass/fail with messages
8. **Warnings:** All engineering warnings
9. **Source References:** Tables and figures used
10. **Software Version:** Engine version, data version

## Report Format

- A4 portrait
- Professional engineering report layout
- Deterministic generation (same inputs → same report)
- PDF output
