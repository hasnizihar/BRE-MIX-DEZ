# UI Specification

## Application Workflow

```
NEW MIX DESIGN
       ↓
Project Information
       ↓
Concrete Requirements (f_ck, workability, age)
       ↓
Material Properties (cement class, aggregate type/size, RD, grading)
       ↓
Specification Limits (max w/c, min/max cement) [optional]
       ↓
BRE Calculation (automatic)
       ↓
Results Display (mix proportions + calculation trace)
       ↓
Field Corrections (moisture, absorption) [optional]
       ↓
Batch Quantities
       ↓
Engineering Checks & Warnings
       ↓
Report (view / print / PDF export)
       ↓
Save Project
```

## Key UI Features

1. **Show Calculation** button — reveals full step-by-step calculation trace
2. **Engineering warnings** — prominent display of ERROR/WARNING/INFO messages
3. **Mix summary** — clear presentation of final mix proportions
4. **Source references** — every result linked to its engineering source
5. **PDF export** — professional report generation
