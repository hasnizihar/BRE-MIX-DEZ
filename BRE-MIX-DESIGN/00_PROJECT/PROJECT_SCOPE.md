# Project Scope

## Project

BRE Concrete Mix Design Desktop Application

## Primary Method

BRE / DoE Method

## Primary Reference

```
Document:  BRE BR 331
Title:     Design of Normal Concrete Mixes
Edition:   Second Edition
Year:      1997
ISBN:      1-86081-172-8
Authors:   D.C. Teychenné, R.E. Franklin, H.C. Erntroy
Publisher: Construction Research Communications Ltd (BRE)
```

## Initial Scope

Normal-weight concrete mix design using the BRE/DoE 5-stage method.

### Included

- Target mean strength calculation (Stage 1)
- Water/cement ratio determination (Stage 1)
- Free water content estimation (Stage 2)
- Cement content calculation (Stage 3)
- Total aggregate content determination (Stage 4)
- Fine/coarse aggregate proportioning (Stage 5)
- Moisture corrections for field batching
- Batch quantity calculations
- Calculation trace and transparency
- PDF report generation

### Supported Cement Types (Initial)

- Portland cement, class 42.5
- Portland cement, class 52.5

### Supported Aggregate Types (Initial)

- Uncrushed (natural/gravel)
- Crushed (stone)

### Supported Aggregate Sizes (Initial)

- 10 mm
- 20 mm
- 40 mm

## Initial Exclusions

The following are **explicitly excluded** from the initial implementation:

- Lightweight concrete
- Heavyweight concrete
- Self-compacting concrete (SCC)
- High-performance concrete (HPC)
- Fibre-reinforced concrete
- Special concretes
- Pumped concrete (unless explicitly supported by BRE method)
- Air-entrained concrete (future scope — BRE provides guidance)
- PFA (pulverised-fuel ash) modifications (future scope — BRE provides guidance)
- GGBS (ground granulated blastfurnace slag) modifications (future scope — BRE provides guidance)
- Automatic material optimization
- BS 8500 compliance verification
- BS EN 206 conformity assessment
- Structural design
- Full durability design (beyond BRE method scope)

## Future Scope

- Air-entrained concrete support
- PFA/GGBS cement combination support
- Additional mix-design methods
- BS 8500 durability input integration
- Exposure class lookup
- Multi-project management

## Application Status

```
Engineering calculation aid
```

The application does NOT claim to be a certified standards-compliance tool.
