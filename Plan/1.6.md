# STEP 6: Use Multiple Test Layers

Each equation should have several types of tests.

### A. Normal case

Known valid input:

```text

```

```text

```

and maximum:


For example:

```text

```

if negative values are physically invalid for that parameter.

### D. Missing-data case

```text

        ↓
EngineeringDataUnavailableError
```

### E. Unit consistency

Check that:

```text
kg
kg/m³
MPa
m³
mm
```

are not accidentally mixed.
